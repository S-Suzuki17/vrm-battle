# ⚔️ 3D 自作キャラバトル (VRM対応)

ブラウザ上で自作の3Dキャラクター（VRMアバター）を読み込み、自動生成される個性豊かなCPUと対決するWeb3D連勝バトルゲームです。

![WebGL](https://img.shields.io/badge/Three.js-0.169.0-black?logo=three.js)
![VRM](https://img.shields.io/badge/@pixiv/three--vrm-2.1.3-blue)
![Platform](https://img.shields.io/badge/Platform-Browser%20(PC%20%2F%20Mobile)-green)

---

## 🌟 特徴

1. **3Dリアルタイム描画 (Three.js)**
   - ネオン輝くサイバーバトルリングとライティング、パーティクル演出
   - ドラッグ操作で360度カメラ視点を回転可能
2. **自作VRMアバターのローカル即時読み込み (`@pixiv/three-vrm`)**
   - ブラウザ上のドロップゾーンに `.vrm` ファイルをドラッグ＆ドロップ（またはファイル選択）するだけで、プレイヤーキャラクターが瞬時に自作アバターへ差し替わります。
   - 完全ローカル処理（メモリ上のみ）のため、サーバーへのデータ送信は一切なく著作権・プライバシー面でも安全です。
3. **動的に変化する4タイプのCPU**
   - 「近接型（拳法家）」「近接型（重戦士：大剣装備）」「狙撃型（サイキッカー：浮遊ビット）」「狙撃型（スナイパー：ライフル装備）」
   - スタイルに合わせた3D武器メッシュ・オーブ・エフェクトが動的に生成されます。
4. **迫力のバトルアクション演出**
   - 突進攻撃、スラッシュ、クリティカルヒット、CPUのノックバック＆吹き飛び、新CPUのリスポーン演出
   - 敗北時のダウン演出とゲームオーバー画面
5. **連勝記録保存 & 𝕏 (旧Twitter) シェア**
   - `localStorage` による自己ベスト記録の自動保存
   - 記録付きの𝕏投稿URLを1クリックで生成

---

## 🚀 起動方法

### 前提環境
- Node.js (v14以降推奨)

### ローカルサーバー起動
外部パッケージの `npm install` は不要です（ゼロ依存）。

```bash
node server.js
```

起動後、表示されるURLにブラウザでアクセスします：
- PCブラウザ: `http://localhost:3000`
- スマホ（同一Wi-Fi環境）: `http://<ローカルIP>:3000`
