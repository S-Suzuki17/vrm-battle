# ⚔️ 3D 自作キャラバトル (アンリミテッド・タイマンコロシアム)

Wii『ワンピース アンリミテッドクルーズ』の対戦モード（タイマンバトル）のフィールドやアクション性をオマージュした、Web3D本格アクション対戦ゲームです。
自作のVRMアバターをブラウザにドロップして、古代遺跡の断崖アリーナを舞台にCPUとリアルタイムで戦えます。

## 🏛️ アンリミ風フィールド & バトルシステム

1. **古代遺跡コロシアムの断崖アリーナ**
   - どこまでも続く青い大海原と断崖絶壁にそびえ立つ石畳の円形コロシアム。
   - 周囲を取り囲む古代神殿の石柱群（一部は崩落・折れた柱）、4基の松明から立ち上る揺らめく炎パーティクルとライティング。
   - プレイヤーと敵を常にドラマチックに収めるTPS対戦カメラアングル。
2. **HP & SP(MP) リソース管理**
   - **HPゲージ**: 被弾時に赤ゲージが遅れて追随する格闘ゲーム/アンリミ風のダイナミックゲージ。
   - **SP/MPゲージ**: 攻撃ヒットや時間経過で蓄積。ステップ回避や必殺技の発動に使用。
3. **本格アクション操作体系**
   - **通常攻撃（3段コンボ）**: 弱攻撃 → 中攻撃 → 吹き飛ばしフィニッシュ。光の斬撃エフェクトが宙を裂きます。
   - **必殺技 (SP 50消費)**: 画面が暗転し、カメラが急接近して技名カットイン演出が炸裂！超巨大な衝撃波で相手を吹き飛ばします。
   - **ガード (防御)**: 青いヘキサゴンバリアを展開し、被ダメージを85%カット。
   - **ステップ回避**: 高速ダッシュで敵の攻撃を回避（無敵時間あり）。
4. **コンボカウンター & 浮動ダメージ数値**
   - 連続ヒット時に「3 HITS! 220 DMG」とダイナミックにポップアップ。
5. **敵CPUの自律戦闘AI**
   - 拳法家（高速コンボラッシュ）、重戦士（大剣豪快撃＆ガード）、サイキッカー（念動弾）、スナイパー（遠距離ライフル）の4スタイル。
   - 状況に応じて接近、後退、ガード、SP50必殺技を繰り出します。
6. **VRMアバターのドラッグ＆ドロップ召喚**
   - 画面内に `.vrm` ファイルをD&Dまたは選択するだけで、自作キャラに瞬時に交代。歩行ボーンアニメーションにも連動。

## 🎮 操作方法

### PCキーボード
| キー | アクション |
| :--- | :--- |
| `W` `A` `S` `D` (または矢印キー) | 360度移動 |
| `J` または `Z` | 通常攻撃（連打で3段コンボ） |
| `K` または `X` | 必殺技（SP 50消費 / カットイン技） |
| `Space` | ガード（被ダメ85%カット） |
| `L` または `Shift` | ステップ回避（SP 15消費） |
| `Q` | ロックオン切替 |

### スマートフォン / タッチデバイス
- **画面左側**: バーチャル移動スティック（360度アナログ移動）
- **画面右側**: ⚔️ [攻撃], ⚡ [必殺], 🛡️ [ガード], 💨 [回避] ボタン
